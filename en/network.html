The brand as specification

Brand Infrastructure
The machine-readable layer of a brand: explicit, parametrizable, for systems.Connected to: Brand Specification (takes shape as), Schema.org / JSON-LD (most effective part), llms.txt (part of it, no visibility effect), Model Context Protocol (route to the brand data)
Brand Specification
The brand in a form that can be applied rather than interpreted.Connected to: Machine Readable Brands (makes possible), Identity File (is stored as), Open Brand Repo (goes public as), Brand Infrastructure (takes shape as), Execution Layer / Layer of Meaning (meaning needs text)
Machine Readable Brands
Brands whose identity, language, and design logic exist as a specification that people and systems can work with equally.Connected to: Agentic Brand Readiness (stage one of it), Brand Specification (makes possible), GEO (starts later)
Identity File
The file that states who a brand is and what it acts on.Connected to: Stateful (must know the history), Brand Specification (is stored as)
Open Brand Repo
The brand specification as a public, versioned repository.Connected to: Design Token (contains), Agent Authority (limits stay internal), Brand Specification (goes public as)
Execution Layer / Layer of Meaning
A brand's two layers: how it looks and sounds (execution), and who it is and what holds for it (meaning).Connected to: Design Token (execution is machine-capable), Brand Specification (meaning needs text)
Design Token
The smallest machine-readable design decision: a color, a spacing, a typeface as a named value.Connected to: Execution Layer / Layer of Meaning (execution is machine-capable), Open Brand Repo (contains)

Being read

Machine Consensus
The picture of a brand that AI systems assemble from every source they can find.Connected to: Answer Engine / AEO (forms inside), Machine View (feeds on), Agentic Brand Readiness (measures it), Stateful (is missing there)
Machine View
A brand as systems process it: source code, structure and markup instead of design.Connected to: Accessibility Tree (shows), Schema.org / JSON-LD (shows), llms.txt (shows), Machine Consensus (feeds on)
Accessibility Tree
The structure the browser computes from every page: all elements with role and name, no layout.Connected to: Browser Agent (is its interface), Agentic Browsing (is measured there), Machine View (shows)
Schema.org / JSON-LD
A shared vocabulary for marking up who or what a website is. JSON-LD is the usual format for it.Connected to: Brand Infrastructure (most effective part), Machine View (shows), Canonical Link (markup in the source)
llms.txt
A text file summarizing a website's most important content for language models.Connected to: Brand Infrastructure (part of it, no visibility effect), Machine View (shows)
Agentic Browsing
An audit category in Google's Lighthouse measuring how well agents can read and operate a website.Connected to: Agentic Brand Readiness (turns it into a score), Accessibility Tree (is measured there)
GEO
Optimizing content for the answer a generative system gives, rather than for a ranking in a list of results.Connected to: Answer Engine / AEO (aims at), Machine Readable Brands (starts later)
Answer Engine / AEO
A system that answers a question directly instead of linking to results. AEO is the practice of optimizing for it.Connected to: Machine Consensus (forms inside), GEO (aims at)
Agentic Brand Readiness
The measurable maturity level of a brand toward AI systems: being found, described correctly, and recommended.Connected to: Machine Consensus (measures it), Machine Readable Brands (stage one of it), Agentic Browsing (turns it into a score)
Canonical Link
The machine-readable commitment declaring which version of a piece of content is the original.Connected to: Schema.org / JSON-LD (markup in the source)

Agents act

Browser Agent
Software operating websites on a user's behalf: comparing, booking, buying instead of just reading.Connected to: Agentic Commerce (acts within), Accessibility Tree (is its interface), Agent Authority (bounds)
Agent Authority
The deliberately granted, bounded, and accounted-for mandate a brand gives its agents.Connected to: Browser Agent (bounds), Agentic Commerce (becomes necessary through), Accountable Decision (needs an address), Open Brand Repo (limits stay internal), Model Context Protocol (gives agents access)
Agentic Commerce
Commerce in which an agent on at least one side compares, negotiates, or buys.Connected to: Agent Authority (becomes necessary through), Browser Agent (acts within), Machine Customers (are its buyers)
Machine Customers
Systems that buy on their own or prepare purchasing decisions.Connected to: Agentic Commerce (are its buyers)
Model Context Protocol
An open standard through which AI systems reach external tools and data sources.Connected to: Agent Authority (gives agents access), Brand Infrastructure (route to the brand data)

What remains

Second List
The short list of brand elements a brand deliberately withholds from the machine.Connected to: Accountable Decision (every item needs one), Consensus Taste (escapes it)
Accountable Decision
The judgment about which option is right: justified, dated, versioned, with a named sender who stands behind it.Connected to: The Bet (becomes testable through), Consensus Taste (is not the middle), Agent Authority (needs an address), Second List (every item needs one)
The Bet
The recommendation that commits: thesis, named failure signal, sender who bears the consequences.Connected to: Accountable Decision (becomes testable through)
Consensus Taste
Taste that can be learned from many examples, and therefore reproduces the middle.Connected to: Accountable Decision (is not the middle), Second List (escapes it)
Stateful
A brand carries its entire history with it. Every statement lands against everything said before.Connected to: Machine Consensus (is missing there), Identity File (must know the history)

Why a network and not a list

These terms did not appear side by side; they came out of one another. Brand Specification is the form that Brand Infrastructure takes. Agent Authority becomes necessary because agents act, and in the end it needs what every accountable decision needs: an address that stands behind it. An alphabetical list shows none of that.

Every connection carries a word. No line is decorative, and where I cannot name a relation, there is none. Four groups order the picture: what a brand has to settle, what systems read of it, what agents do with it, and what remains with the human at the end.
