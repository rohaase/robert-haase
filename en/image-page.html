Image page.

This page is built like a brand's campaign page: mood image, claim, gallery, ornament. Next to it, Machine View shows what a machine receives from each of these images. Some arrive, most do not. The faults are intentional, which is why the page is excluded from indexing.

One: The mood image

The only image on this page that arrives, as exactly one sentence. The mood, the composition, the colour world, everything the image was chosen for, stays behind. (Technically: a descriptive alt text.)

Two: The claim

The most important sentence of the campaign sits inside the image. The machine reads only "Campaign visual". Formally everything is labelled, the message is still gone. The most common case on real brand pages. (Technically: alt text present, but without the claim.)

Three: The gallery

Three carefully chosen motifs. The machine only knows: something hangs here, three times. The world these images open up does not arrive. (Technically: images without an alt attribute, nameless nodes in the tree.)

Four: The ornament

The ornament is not meant to say anything, and it says nothing. The one case on this page where disappearing is correct. (Technically: empty alt plus role="presentation".)

Five: The backdrop

This paragraph sits on an image that exists only in the stylesheet.

The large image behind the text carries the atmosphere. For the machine there is not even an image here, it lives only in the stylesheet, not in the document. (Technically: a CSS background image, no node, nothing to name.)

Six: The teaser image

The image leads to the most important subpage on click. The machine sees a link with no name and can only guess where it goes. Operable but mute, the worst case. (Technically: a linked image without a label.)

Seven: The icon

Icon with no title, deliberately marked as hidden here.

The icon next to the text is ornament with meaning, for people. For the machine it is empty. Here it is deliberately marked as hidden; otherwise it would be a silent loss. (Technically: an SVG without a title, with aria-hidden.)

What the comparison shows

Of the seven image cases on this page, one arrives carrying its meaning. One disappears deliberately and correctly. Five are lost.

This is not a badly built page, it is an ordinary one. These cases are everyday practice: claims inside images, galleries without labels, backgrounds in the stylesheet, linked images without names. Anyone running a brand visually runs a large part of it outside what machines can reach.

The conclusion is not to describe every image at length. Alt text is meant to be functional, not exhaustive. The conclusion is that load-bearing statements must not live in the image alone. Whatever is meant to hold has to exist as text as well — the claim in case two is the clearest proof, and that is the core of Machine Readable Brands.

To check: open this page in Machine View and pick "Image page" in the page selector.
