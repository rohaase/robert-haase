Für Basti

Deine Website mit Claude Code

Gleiches Setup wie meins: kein WordPress, kein CMS, keine Updates. Deine Texte liegen als einfache Dateien in einem Ordner, und Claude Code macht den Rest. Du sagst auf Deutsch, was du willst.

Vier Etappen. Nach Etappe 3 ist deine Seite online.

Plan dir für den ersten Durchgang zwei Stunden ein, nicht zwanzig Minuten. Die Zeit steckt im Einrichten, danach dauert ein neuer Blogbeitrag fünf Minuten.

So funktioniert diese Seite: Die grauen Kästen sind zum Kopieren gedacht. Auf „Kopieren" drücken, dann in Claude Code ins Schreibfeld einfügen und abschicken, wie eine normale Nachricht. Einzige Ausnahme ist der Kasten in Etappe 1, der gehört in das Namensfeld bei GitHub.

Und das Prinzip gilt für die ganze Seite: Du kannst jeden Schritt hier markieren, kopieren und Claude Code geben. Oder du machst einen Screenshot von dem, was du gerade vor dir hast, und ziehst ihn ins Schreibfeld. Dazu „Hilf mir bei diesem Schritt" — Claude führt dich dann durch, auch bei allem, was bei GitHub oder deiner Domain passiert.

Etappe 0 — Die drei Accounts (15 Minuten)

  1. GitHub (kostenlos): auf github.com auf „Sign up". Der Benutzername taucht später in der Adresse deiner Seite auf, nimm also sebastiantrieb und nicht xXsebi92Xx.
  2. Claude: auf claude.ai anmelden.
  3. Claude Pro: hier musst du einmal ehrlich schlucken. Claude Code ist im kostenlosen Tarif nicht enthalten, du brauchst mindestens Pro. Das ist neben der Domain in Etappe 4 (ungefähr 10 bis 20 Euro im Jahr, und nur wenn du eine eigene Adresse willst) der einzige Posten, der Geld kostet. Hosting: null. Deine Seite läuft erst mal komplett kostenlos unter deinbenutzername.github.io.

Falls du das erst sehen willst, bevor du zahlst: sag mir Bescheid, dann bauen wir Etappe 1 und 2 zusammen im Browser, das geht auch ohne. Aber der bequeme Weg ist dieser hier.

Etappe 1 — Deine Seite entsteht (15 Minuten, alles im Browser)

  1. Öffne meine Vorlage: Neue Website aus der Vorlage erstellen. („Repository", kurz Repo, ist einfach der Ordner, in dem eine Website liegt. Der Link bringt dich direkt in den Erstellen-Dialog.)
  2. Als Namen nimmst du exakt: 
    deinbenutzername.github.io
    Also z. B. sebastiantrieb.github.io, mit deinem Benutzernamen. Genau so, mit .github.io hinten dran: daran erkennt GitHub, dass daraus eine Website werden soll.
  3. Public auswählen. Wichtig: Im kostenlosen GitHub-Tarif baut GitHub aus einem privaten Repo gar keine Website.
  4. Im neuen Repo: Settings → linke Spalte Pages. Bei einem Repo, das deinbenutzername.github.io heißt, schaltet GitHub die Website normalerweise von selbst scharf. Steht da nichts: nicht schlimm, merk es dir. Claude Code prüft das gleich für dich.
  5. Zwei Minuten warten, dann https://deinbenutzername.github.io aufrufen. Da stehen jetzt die Platzhalter-Texte der Vorlage. Genau richtig.

Etappe 2 — Zwei Programme installieren (20 Minuten)

GitHub Desktop (desktop.github.com)

Das ist die Brücke zwischen dem Ordner auf deinem Rechner und der Website im Netz. Installieren, mit deinem GitHub-Account einloggen, dann „Clone a repository" → dein deinbenutzername.github.io auswählen → Clone.

Jetzt liegt deine Website als ganz normaler Ordner auf deinem Rechner. Merk dir, wo.

Warum dieses Programm: Es erledigt das Anmelden gegenüber GitHub mit zwei Klicks. Ohne läuft man als Einsteiger fast garantiert in eine Passwort-Fehlermeldung, die niemand versteht. Der Umweg spart dir eine Stunde Frust.

Claude Code (claude.com/download)

Es gibt eine normale Desktop-App für Mac und Windows. Du brauchst kein Terminal, keine Kommandozeile, nichts Schwarzes mit blinkendem Cursor. Installieren und mit deinem Claude-Account einloggen.

Wichtig: Die App startet im normalen Chat. Schalte in der Seitenleiste auf „Code" um — das ist der Bereich, in dem Claude direkt mit deinen Dateien arbeiten kann. Dort öffnest du dann den Ordner, den GitHub Desktop gerade angelegt hat.

Eine Sache noch, bevor du lostippst: Beim ersten Arbeiten fragt Claude Code dich um Erlaubnis, wenn er Dateien ändern oder etwas ausführen will, zum Beispiel beim Online-Bringen. Das sind kleine Dialoge mit „Erlauben"/„Allow". Lies kurz, was er vorhat, und bestätige. Und wenn mal scheinbar nichts passiert: Schau, ob so eine Frage auf deine Antwort wartet. Das ist der häufigste Grund, warum es „hängt".

Etappe 3 — Die erste Unterhaltung

Jetzt der Teil, der sich komisch anfühlt und dann sofort klickt: Du schreibst Claude Code einfach, was du willst.

Fang genau so an, kopier das ins Schreibfeld von Claude Code:

Das hier ist meine persönliche Website, gehostet auf GitHub Pages. Ich habe null Vorerfahrung mit Code, Git oder Markdown.

Schau dir zuerst an, wie dieses Projekt aufgebaut ist, und erklär mir in maximal zehn Sätzen: Welche Dateien enthalten die Texte, wo liegen die Blogbeiträge, und wo kommen Bilder hin? Keine technischen Hintergründe, nur was ich zum Arbeiten wissen muss.

Danach warte auf mich. Arbeite ab jetzt immer nur einen Schritt auf einmal und frag mich, bevor du etwas Größeres änderst.

Der letzte Absatz ist wichtig. Ohne ihn baut er dir mit Begeisterung ein Fundament um, das du gar nicht anfassen wolltest.

Dann der Reihe nach, ein Prompt pro Baustein:

Ersetze das Intro auf der Startseite. Frag mich vorher der Reihe nach ab, was drinstehen soll — eine Frage pro Nachricht.
Fülle die Seite mit meinen Stationen. Ich diktiere sie dir gleich als Rohtext, du bringst sie in die Struktur, die zu dieser Website passt.
Lege einen Blogbeitrag an mit dem Titel [Titel]. Zeig mir vorher, wie die Datei heißen wird und wo sie landet.

Und wenn es fertig aussieht:

Bring die Änderungen online und sag mir, wann ich sie sehen kann.

Alternativ machst du das in GitHub Desktop selbst: unten links kurz reinschreiben, was du geändert hast, „Commit to main", dann oben „Push origin". Zwei Minuten später ist es live.

Das ist der ganze Kreislauf. Ändern → committen → pushen → live. Mehr passiert bei dieser Art Website nie.

Etappe 4 — Deine Domain draufsetzen (20 Minuten, in Ruhe)

Falls du noch keine Domain hast: Hol dir eine bei Domain Factory (df.eu), dann passen die Schritte unten eins zu eins zu deinem Kundenmenü. Eine .de-Domain kostet ungefähr 10 bis 20 Euro im Jahr. Registrieren reicht, kein Hosting-Paket dazubuchen: Die Seite liegt ja schon bei GitHub, du biegst nur die Adresse um.

Es ändern sich nur zwei Dinge.

Bei GitHub: Settings → Pages → „Custom domain" → deine Domain eintragen → Save. Dadurch entsteht im Repo eine Datei namens CNAME. Die nicht löschen.

Bei Domain Factory (Kundenmenü → DNS-Verwaltung):

  • Vier A-Records für die nackte Domain: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153
  • Ein CNAME-Record für www, der auf deinbenutzername.github.io zeigt.

(Falls GitHub in seiner Doku andere Werte nennt: GitHub gewinnt. Steht unter „Managing a custom domain for your GitHub Pages site".)

Danach kann es bis zu 24 Stunden dauern. Nicht nervös werden. Zum Schluss bei GitHub noch „Enforce HTTPS" anhaken, dann hat deine Seite das Schloss im Browser.

Das ist die einzige Stelle, an der man wirklich etwas kaputtmachen kann. Deshalb: nicht zwischen Tür und Angel. Wenn du unsicher bist, mach einen Screenshot von der DNS-Seite und frag Claude Code, bevor du auf Speichern drückst.

Die fünf Dinge, die den Unterschied machen

  1. Kleine Schritte. „Ändere das Intro" funktioniert. „Bau mir die Seite neu" produziert zuverlässig Murks.
  2. Lies, bevor du bestätigst. Er zeigt dir, was er ändern will. Ein Blick drauf, dann OK.
  3. Sag ihm, wenn dir etwas nicht gefällt. „Zu lang, halbier das" ist ein völlig ausreichender Prompt.
  4. Wenn etwas kaputtgeht: einfach hinschreiben, was du siehst. Fehlermeldung reinkopieren oder Screenshot. Das ist keine Notlösung, das ist der normale Weg.
  5. Nichts geht verloren, sobald es einmal online war. Jeder hochgeladene Stand liegt in GitHub, man kann immer zurück. Nur was noch nie online gebracht wurde, kann weg sein — darum ruhig oft online bringen. Trau dich, Dinge auszuprobieren.

Kurzfassung

  1. GitHub-Account, Claude Pro.
  2. Meine Vorlage nehmen, deinname.github.io, public.
  3. GitHub Desktop + Claude Code installieren, Repo klonen, Ordner öffnen.
  4. Mit dem Prompt aus Etappe 3 anfangen und dich durchfragen.
  5. Eigene Domain holen und umbiegen, zum Schluss und in Ruhe.

Häng nicht am Design fest, bevor Text drinsteht. Eine schlichte Seite mit gutem Intro schlägt eine schöne leere.
