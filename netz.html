Netz der Begriffe.

Ein Glossar ist eine Liste, und eine Liste verschweigt, was zusammenhängt. Hier stehen dieselben 27 Begriffe als Netz: 36 Verbindungen, jede mit einem Wort dafür, wie die beiden zusammenhängen.

Zeig mit der Maus auf einen Begriff, dann treten er und seine Nachbarn hervor, und unter der Grafik steht, was er bedeutet und woran er hängt. Ein Klick führt zur ausführlichen Definition im Glossar, ein Doppelklick hält die Auswahl fest. Mit der Tastatur geht dasselbe über die Tabulator-Taste.

Die Marke als Spezifikation

Brand Infrastructure
Die maschinenlesbare Schicht der Marke: explizit, parametrisierbar, für Systeme.Verbunden mit: Marken-Spezifikation (nimmt Form an als), Schema.org / JSON-LD (wirksamster Teil), llms.txt (Teil, ohne Sichtbarkeits-Wirkung), Model Context Protocol (Weg zu den Markendaten)
Marken-Spezifikation
Die Marke in einer Form, die sich anwenden lässt statt gedeutet werden zu müssen.Verbunden mit: Machine Readable Brands (macht möglich), Identitätsdatei (wird abgelegt als), Open Brand Repo (wird öffentlich als), Brand Infrastructure (nimmt Form an als), Ausführungsschicht / Bedeutungsschicht (Bedeutung braucht Text)
Machine Readable Brands
Marken, deren Identität, Sprache und Designlogik als Spezifikation vorliegen, mit der Menschen und Systeme gleichermaßen arbeiten können.Verbunden mit: Agentic Brand Readiness (Stufe eins davon), Marken-Spezifikation (macht möglich), GEO (setzt später an)
Identitätsdatei
Die Datei, in der festgelegt ist, wer eine Marke ist und wonach sie handelt.Verbunden mit: Stateful (muss den Verlauf kennen), Marken-Spezifikation (wird abgelegt als)
Open Brand Repo
Die Marken-Spezifikation als öffentliches, versioniertes Repository.Verbunden mit: Design-Token (enthält), Agent Authority (Grenzen bleiben intern), Marken-Spezifikation (wird öffentlich als)
Ausführungsschicht / Bedeutungsschicht
Die zwei Schichten einer Marke: wie sie aussieht und klingt (Ausführung), und wer sie ist und was für sie gilt (Bedeutung).Verbunden mit: Design-Token (Ausführung ist maschinenfähig), Marken-Spezifikation (Bedeutung braucht Text)
Design-Token
Die kleinste maschinenlesbare Gestaltungsentscheidung: eine Farbe, ein Abstand, eine Schrift als benannter Wert.Verbunden mit: Ausführungsschicht / Bedeutungsschicht (Ausführung ist maschinenfähig), Open Brand Repo (enthält)

Gelesen werden

Maschinen-Konsens
Das Markenbild, das KI-Systeme aus allen auffindbaren Quellen zusammensetzen.Verbunden mit: Answer Engine / AEO (entsteht in), Maschinensicht (speist sich aus), Agentic Brand Readiness (misst ihn), Stateful (fehlt dort)
Maschinensicht
Der Blick auf eine Marke, wie Systeme sie verarbeiten: Quelltext, Struktur und Auszeichnung statt Gestaltung.Verbunden mit: Accessibility-Baum (zeigt), Schema.org / JSON-LD (zeigt), llms.txt (zeigt), Maschinen-Konsens (speist sich aus)
Accessibility-Baum
Die Struktur, die der Browser aus jeder Seite errechnet: alle Elemente mit Rolle und Name, ohne Layout.Verbunden mit: Browser-Agent (ist dessen Schnittstelle), Agentic Browsing (wird dort gemessen), Maschinensicht (zeigt)
Schema.org / JSON-LD
Gemeinsames Vokabular, mit dem Websites auszeichnen, wer oder was sie sind. JSON-LD ist das übliche Format dafür.Verbunden mit: Brand Infrastructure (wirksamster Teil), Maschinensicht (zeigt), Canonical-Link (Auszeichnung im Quelltext)
llms.txt
Textdatei, die die wichtigsten Inhalte einer Website für Sprachmodelle zusammenfasst.Verbunden mit: Brand Infrastructure (Teil, ohne Sichtbarkeits-Wirkung), Maschinensicht (zeigt)
Agentic Browsing
Prüfkategorie in Googles Lighthouse, die misst, wie gut Agenten eine Website lesen und bedienen können.Verbunden mit: Agentic Brand Readiness (macht sie zum Score), Accessibility-Baum (wird dort gemessen)
GEO
Optimierung von Inhalten für die Antwort generativer Systeme statt für ein Ranking in einer Ergebnisliste.Verbunden mit: Answer Engine / AEO (zielt auf), Machine Readable Brands (setzt später an)
Answer Engine / AEO
System, das eine Frage direkt beantwortet, statt Ergebnisse zu verlinken. AEO ist die Optimierung darauf.Verbunden mit: Maschinen-Konsens (entsteht in), GEO (zielt auf)
Agentic Brand Readiness
Der messbare Reifegrad einer Marke gegenüber KI-Systemen: gefunden, korrekt beschrieben und empfohlen werden.Verbunden mit: Maschinen-Konsens (misst ihn), Machine Readable Brands (Stufe eins davon), Agentic Browsing (macht sie zum Score)
Canonical-Link
Die maschinenlesbare Festlegung, welche Version eines Inhalts das Original ist.Verbunden mit: Schema.org / JSON-LD (Auszeichnung im Quelltext)

Agenten handeln

Browser-Agent
Software, die im Auftrag eines Nutzers Websites bedient: vergleicht, bucht, kauft, statt nur zu lesen.Verbunden mit: Agentic Commerce (handelt in), Accessibility-Baum (ist dessen Schnittstelle), Agent Authority (begrenzt)
Agent Authority
Die bewusst erteilte, begrenzte und verantwortete Handlungsvollmacht einer Marke an ihre Agenten.Verbunden mit: Browser-Agent (begrenzt), Agentic Commerce (wird nötig durch), Verantwortete Entscheidung (braucht eine Adresse), Open Brand Repo (Grenzen bleiben intern), Model Context Protocol (gibt Agenten Zugriff)
Agentic Commerce
Handel, bei dem auf mindestens einer Seite ein Agent vergleicht, verhandelt oder kauft.Verbunden mit: Agent Authority (wird nötig durch), Browser-Agent (handelt in), Machine Customers (sind dessen Käufer)
Machine Customers
Systeme, die eigenständig kaufen oder Kaufentscheidungen vorbereiten.Verbunden mit: Agentic Commerce (sind dessen Käufer)
Model Context Protocol
Offener Standard, über den KI-Systeme auf externe Werkzeuge und Datenquellen zugreifen.Verbunden mit: Agent Authority (gibt Agenten Zugriff), Brand Infrastructure (Weg zu den Markendaten)

Was bleibt

Zweite Liste
Die kurze Liste der Markenelemente, die eine Marke der Maschine bewusst entzieht.Verbunden mit: Verantwortete Entscheidung (jeder Punkt braucht eine), Konsens-Geschmack (entzieht sich ihm)
Verantwortete Entscheidung
Das Urteil, welche Variante richtig ist: begründet, datiert, versioniert, mit einem Absender, der dafür geradesteht.Verbunden mit: Scheiter-Signal (wird prüfbar durch), Konsens-Geschmack (ist nicht die Mitte), Agent Authority (braucht eine Adresse), Zweite Liste (jeder Punkt braucht eine)
Scheiter-Signal
Das benannte Ereignis, an dem eine Empfehlung erkennbar scheitert.Verbunden mit: Verantwortete Entscheidung (wird prüfbar durch)
Konsens-Geschmack
Geschmack, der sich aus vielen Beispielen lernen lässt und deshalb die Mitte abbildet.Verbunden mit: Verantwortete Entscheidung (ist nicht die Mitte), Zweite Liste (entzieht sich ihm)
Stateful
Eine Marke trägt ihren gesamten Verlauf mit. Jede Aussage wirkt gegen alles, was vorher gesagt wurde.Verbunden mit: Maschinen-Konsens (fehlt dort), Identitätsdatei (muss den Verlauf kennen)

Warum ein Netz und keine Liste

Die Begriffe sind nicht nebeneinander entstanden, sondern auseinander. Marken-Spezifikation ist die Form, die Brand Infrastructure annimmt. Agent Authority wird nötig, weil Agenten handeln, und braucht am Ende dasselbe wie jede verantwortete Entscheidung: eine Adresse, die geradesteht. Eine alphabetische Liste zeigt davon nichts.

Jede Verbindung trägt ein Wort. Keine Linie ist dekorativ, und wo ich keinen Zusammenhang benennen kann, steht auch keine. Vier Gruppen ordnen das Bild: was eine Marke festlegen muss, was Systeme davon lesen, was Agenten damit tun, und was am Ende beim Menschen bleibt.
